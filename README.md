# Ohm-s-Law-Calculator

A simple Python command-line project that calculates voltage, current,
or resistance using Ohm's Law.

## About the Project

Ohm's Law describes the relationship between voltage, current, and
resistance in an electrical circuit.

The calculator allows the user to calculate:

- Voltage
- Current
- Resistance

This project was created as a beginner-level Python project for
Electrical/Electronics Engineering students.

## Formula

The main formulas used are:

V = I × R

I = V / R

R = V / I

Where:

- V = Voltage in Volts (V)
- I = Current in Amperes (A)
- R = Resistance in Ohms (Ω)

## Features

- Calculate voltage
- Calculate current
- Calculate resistance
- Input validation
- Handles division-by-zero errors
- Simple command-line interface
- No external Python packages required
